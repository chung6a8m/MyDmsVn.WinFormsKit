# A3 — Khởi tạo MyDmsVn.WinFormsKit

**Ngày:** 24/10/2026. Đây là nơi duy nhất ghi trạng thái thực thi A3 của repository.

**Mục tiêu:** tạo nền tảng source, project graph, galleries, tests và tài liệu để phát triển UI core cùng adapter trong `chung6a8m/MyDmsVn.WinFormsKit`.

**Phạm vi được giao:** Owner yêu cầu đọc MyDmsVn.Docs, khởi tạo source/tài liệu để thực hiện A3 và commit vào repository WinFormsKit. Chỉ dẫn này cho phép bootstrap được mô tả ở đây; không tự chọn các phương án runtime/API/Web khác trong Docs và không chuyển consumer sản phẩm.

**Thiết kế:** [ARCHITECTURE](../ARCHITECTURE.md). UI core và adapter là source nội bộ với identities cũ; SourceGrid giữ gitlink riêng. Source consumption dùng `ProjectReference`.

**Stack:** native WinForms, `net48;net8.0-windows`, SDK baseline `8.0.400`/`latestFeature`; NUnit và test dependencies giữ phiên bản import. Các ràng buộc A3 gốc nằm trong [organization][design] và [adoption][adoption].

## Ràng buộc xuyên suốt

- Giữ hai assembly/package identities, public APIs, namespaces và cả hai target frameworks. UI core không tham chiếu adapter/engine.
- Toolkit chứa generic controls/grid; product giữ DTO, session, permission và nghiệp vụ. Không dựng Sales UI Lab trong toolkit.
- Giữ tests gốc, helper host và gallery dependencies; không retirement test diện rộng trong bootstrap.
- Giữ notices và license theo component; package publication là bước riêng có điều kiện.
- Không thay consumer app, SQL schema, runtime hoặc SourceGrid pin; không archive/xóa repos nguồn.
- Lệnh và evidence theo candidate thật. Windows/native chưa chạy ghi `NOT RUN` hoặc `BLOCKED`, không lấy historical PASS thay thế.
- Một plan hiện hành; không thêm approval manifests, test runner framework hoặc skills chưa được thử trên công việc thật.

## M1 — Consumer migration riêng

Thực hiện khi công việc consumer được giao, theo [CONSUMER_MIGRATION](../CONSUMER_MIGRATION.md). Pin một commit toolkit cụ thể, thay references của app/solutions/build scripts, chạy owning controls/adapter/native app checks, rồi kiểm rollback về BSG/UI/engine pins đã ghi. Giữ `net48` và production composition của app. Không archive repos nguồn trong bước đầu.

**A3 chỉ được đóng** khi build graph mới, source provenance và consumer/native compatibility có evidence tương ứng. Source bootstrap có thể được commit trước; phần Windows/native hoặc consumer còn thiếu phải giữ trạng thái mở rõ ràng.
